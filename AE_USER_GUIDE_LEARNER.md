# Guide apprenant — AE Apprendre

Bienvenue sur **AE Apprendre**, la plateforme d’Action Éducation pour apprendre **sans Internet**.

## Se connecter

1. Demandez l’adresse du serveur à votre formateur (exemple : `http://192.168.1.20:8000`).
2. Entrez votre **nom d’utilisateur** et votre **mot de passe**.
3. Vous arrivez sur la page d’accueil AE Apprendre.

## Page d’accueil

Sur l’accueil vous pouvez :

- **Continuer** un contenu déjà commencé ;
- ouvrir le **catalogue** ;
- voir les **vidéos**, les **quiz**, votre **progression** ;
- ouvrir l’**aide**.

Tout fonctionne sur le réseau local de la formation : pas besoin de données mobiles.

## Suivre une formation

1. Ouvrez **Catalogue** ou **Vidéos** / **Quiz**.
2. Choisissez un contenu.
3. Le lecteur s’ouvre (vidéo, document, exercice).
4. Votre progression est enregistrée automatiquement.

## Pendant une session en présentiel

Votre formateur peut :

- vous **inscrire** à une session ;
- noter votre **présence** ;
- vous délivrer un **certificat** à la fin.

Vous n’avez rien à configurer pour cela.

## En cas de problème

- Vérifiez que vous êtes sur le **même Wi‑Fi** que le serveur.
- Réessayez de vous connecter.
- Demandez de l’aide à votre formateur (page **Aide** sur le portal).

Bon apprentissage !
