# Guide formateur — AE Apprendre

Ce guide est pour les **formateurs** qui animent des sessions avec AE Apprendre.

## Se connecter

1. Sur tablette ou ordinateur, ouvrir l’adresse du serveur (exemple : `http://192.168.1.20:8000`).
2. Entrer votre nom d’utilisateur et votre mot de passe.
3. Vous arrivez sur l’accueil **AE Apprendre**.

## Tableau de bord formateur

Depuis l’accueil, ouvrir **Formateur** (`#/trainer`) :

- Voir le nombre de formations, sessions, inscriptions et présences.
- Accéder aux **sessions du jour**.
- Ouvrir **Certificats** et **Rapports**.

## Créer une session

1. Aller dans **Sessions** (`#/trainer/sessions`).
2. Remplir :
   - titre de la formation ;
   - lieu ;
   - date et heure de début (exemple : `2026-07-23T14:00`).
3. Cliquer sur **Créer la session**.

## Inscrire les apprenants et noter les présences

1. Ouvrir la session → **Présences**.
2. Ajouter un apprenant avec son **nom d’utilisateur**.
3. Marquer : Présent / Absent / En retard / Excusé.
4. Les données restent sur le serveur local (pas besoin d’Internet).

## Certificats

1. Aller dans **Certificats**.
2. Choisir la formation et saisir le nom d’utilisateur de l’apprenant.
3. Cliquer sur **Délivrer le certificat**.
4. Utiliser **Imprimer** pour ouvrir la page HTML et imprimer (ou enregistrer en PDF via le navigateur).

## Rapports (CSV)

Dans **Rapports** :

- télécharger toutes les certificats ;
- télécharger les présences d’une session ;
- télécharger les inscriptions d’une formation.

Les fichiers CSV s’ouvrent dans Excel (séparateur `;`, accentuation française).

## Conseils terrain

- Préparer les comptes **avant** l’atelier.
- Si un contenu ne s’ouvre pas, vérifier qu’il est bien **importé** sur le serveur (pas seulement en ligne).
- En cas de doute, demander à l’administrateur du serveur.
